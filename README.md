# STEDI Machine Learning Computer Science Project

## Structure
**notebooks/** holds all of the Databricks or Jupyter notebooks we are going to use for ETL tasks.
**sql/** holds the independent SQL transformation files
**etl_pipeline/** holds the Python scripts or workflow files we use for automation
**data_samples/** groups small example datasets for testing

## Running the Project
Take one of the notebooks under **notebooks/** and run through Databricks. This may require the Databricks Account be connected to the Github account holding this Repo.

## Project Purpose
We are cleaning collected data from a STEDI device for the purpose of training a Machine Learning program to recognize trends and patterns through our cleaned data. This Repo holds the structure and files where this study and educational experiment will be gathered.
